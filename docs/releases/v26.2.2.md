# Cardboard 26.2.2

Cardboard 26.2.2 is a compatibility patch for Minecraft 26.2 focused on preserving interactive Adventure chat components sent by Bukkit/Paper plugins.

## Highlights

- Adds a concrete Adventure `Component` delivery path for `CraftPlayer`.
- Preserves `hover_event` and `click_event` metadata instead of degrading interactive chat components to plain text.
- Restores plugin features such as hover text, clickable links, command suggestions and copy-to-clipboard actions.
- Uses Cardboard's `PaperAdventure` serializer to convert Adventure components into native Minecraft chat components before delivery.
- Keeps the compatibility implementation isolated in its own mixin configuration.

## Validation

- The Cardboard 26.2 build and reproducibility checks passed for the compatibility patch before merge.
- The fix was tested with CloverChat 1.7.3 on Cardboard 26.2 and restores the component delivery path used by its interactive chat features.

This release remains targeted at Minecraft 26.2, Fabric Loader 0.19.3, Fabric API 0.156.0+26.2 and JDK 25.
