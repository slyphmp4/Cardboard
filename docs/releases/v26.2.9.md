# Cardboard 26.2.9

Cardboard 26.2.9 removes a leftover debug print from the `SimpleContainer` Bukkit owner fallback.

- Removes repeated `NULL HOLD!` messages from the server console when a `SimpleContainer` has no active viewer.
- Keeps the existing `bukkitOwner` fallback behavior unchanged.

## Validation target

- Minecraft 26.2
- Fabric Loader 0.19.3
- JDK 25

Release tag: `v26.2.9`.
