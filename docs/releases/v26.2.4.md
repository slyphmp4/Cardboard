# Cardboard 26.2.4

Cardboard 26.2.4 fixes a compatibility regression in the 26.2.3 modded inventory holder fallback.

## Fixes

- Fixes `IllegalStateException: Unexpected BlockState` still being thrown when CoreProtect inspects Storage Delight and other unsupported modded container block entities.
- Detects modded blocks from Minecraft's native block registry instead of Bukkit `Material#getKey()`.
- Keeps vanilla `minecraft:*` BlockState invariant failures strict and unchanged.

## Validation

- Target: Minecraft 26.2, Fabric Loader 0.19.3, JDK 25.
- Reproduced against Storage Delight 26.7.1-26.2-fabric with CoreProtect 24.0 on Cardboard 26.2.3.
