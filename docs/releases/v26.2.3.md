# Cardboard 26.2.3

Cardboard 26.2.3 is a compatibility patch for Minecraft 26.2 focused on modded container block entities used through Bukkit/Paper inventory integrations.

## Highlights

- Prevents `InventoryClickEvent` handlers from failing when plugins inspect the holder of an unsupported modded container block entity.
- Fixes the `IllegalStateException: Unexpected BlockState` path seen with Storage Delight cabinets and CoreProtect.
- Keeps vanilla `minecraft:*` block-state validation strict so genuine CraftBukkit registration problems are not silently hidden.
- Returns an unknown/null inventory holder only for unsupported non-vanilla block types instead of aborting the plugin event.
- Uses Bukkit material keys for namespace detection, avoiding unstable NMS resource-location class names on Minecraft 26.2.
