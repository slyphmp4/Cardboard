# Cardboard 26.2.8

Cardboard 26.2.8 fixes two runtime compatibility issues exposed by CoreProtect and modded block inventories on Minecraft 26.2.

## Fixes

- Resolves the real Bukkit player for fallback `CustomInventoryView` instances created for generic/modded container menus.
- Prevents `InventoryClickEvent#getWhoClicked()` from being null for modded menus such as Storage Delight cabinets.
- Restores a valid bottom player inventory for fallback inventory views, preventing `CraftInventoryView#getBottomInventory()` failures in plugins.
- Guards `ServerCommonPacketListenerImpl#send(Packet)` against null packets returned by modded `BlockEntity#getUpdatePacket()` implementations.
- Prevents cancelled block-inspection interactions from aborting packet handling with `Packet.isTerminal()` null-pointer exceptions.

## Validation target

- Minecraft 26.2
- Fabric Loader 0.19.3
- CoreProtect 24.0
- CoreProtectModdedContainers 1.0.0
- Storage Delight 26.7.1-26.2-fabric
- JDK 25

This follows 26.2.7, which restored CoreProtect container transaction logging for generic modded block inventories.
