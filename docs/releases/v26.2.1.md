# Cardboard 26.2.1

Cardboard 26.2.1 targets Minecraft 26.2 with Fabric Loader 0.19.3, Fabric API 0.156.0+26.2, Paper API 26.2.build.110-stable, and JDK 25.

## Highlights

- Restores the Paper-added `ClientboundPlayerInfoUpdatePacket` constructors required by Paper NMS plugins such as TAB 6.1.2.
- Fixes `/tab reload` failing with `NoSuchMethodError` and disconnecting connected players.
- Restores reused player state during respawn.
- Preserves enabled feature flags when Cardboard rebuilds commands.
- Preserves throwable causes in `BukkitLogger`.
- Fixes MixinInfo annotation parsing compatibility.
- Removes the anonymous `OptionParser` class from the Minecraft main entry point compatibility patch.
- Removes stray null block-tag debug output.

## Validation

- `./gradlew clean build` completed successfully on the production VPS.
- Cardboard 26.2 was deployed with TAB 6.1.2 and reached a normal server startup.
- `/tab reload` was executed twice while connected; both reloads completed successfully with no `ClientboundPlayerInfoUpdatePacket` `NoSuchMethodError` and no disconnect.

The TAB warning about a player group named `(none)` not being present in the sorting list is a separate permissions/configuration issue and is not caused by Cardboard.
